\section{やりたいこととやること}
Type-1 X-ray burstの電波フレアについて、そのバックグラウンド放射のfluxを推定したい。

ここでは、観測データ(標本)のうち\(t_{\mathrm{xrb}} < 0\)
を満たす領域をバックグラウンド放射として扱う。また、
バックグラウンド放射のfluxは時間に依らず一定であると仮定する。
この仮定の下で、標本から
バックグラウンド放射fluxの推定母平均$\fbghat$および
推定母平均の不確かさ$\sigma(\fbghat)$を求める。

\section{推定母平均とその不確かさ}
われわれの仮定の下では、
\(t<\qty{0}{\min}\)を満たす各標本点$f_i$は、
時間に依存しないバックグラウンド放射$f_{\bg}$
と測定誤差$\epsilon_i$を用いて
\begin{equation}
  \label{eq:flux_prexrb}
  f_i = f_{\bg} + \epsilon_i  \: (i:t<\qty{0}{\min})
\end{equation}
と表せる。$f_{\bg}$は母平均に対応している。
異なる時刻、すなわち
異なる$i$における$f_i$および$\epsilon_i$は
互いに独立だと考えてよいだろう。
測定誤差$\epsilon_i$が正規分布\(N(0,\sigma_i)\)に従う場合、
推定母平均$\hat{f}_{\bg}$は以下で与えられる:
\begin{equation}
  \hat{f}_{\bg} = \frac{1}{W}\sum_{i} w_i f_i
\end{equation}
ただし\(w_i \coloneq 1/\sigma_i^2, W=\sum_{i}w_i\)である。

推定母平均$\hat{f}_{\bg}$は真の値(あるいは母平均$f_{\bg}$)からズレているはずである。
ズレの度合いを表す量として不確かさ$\sigma(\hat{f}_{\bg})$を求める必要がある。
\(\sigma(\hat{f}_{\bg})\)は母分散\(\variance(\hat{f}_{\bg})\)から推定できる。
いま、異なる$i$に対して$w_i\fnui$は互いに独立なので
母分散\(\variance(\fbghat)\)は
\begin{empheq}{align}
  \variance(\fbghat) 
  &= \frac{1}{W^2}\variance\ab(\sum_i w_i\fnui)
  = \frac{1}{W^2}\sum_i\ab(w_i^2\variance(\fnui)) \\
  &= \frac{1}{W^2}\sum_i\ab(w_i^2\sigma_i^2)
  = \frac{1}{W^2}W \\
  &= \frac{1}{W}
\end{empheq}
で与えられる。よって
\begin{equation}
  \sigma(\fbghat) = \sqrt{\variance(\fbghat)} = \sqrt{\frac{1}{W}}
\end{equation}
となる。

以上から、バックグラウンド放射fluxは$\fbghat$に対して$\sigma(\fbghat)$の不確かさで
分布していると推定される。

\section{フレア領域への影響}
理論モデルと観測との比較は、
バックグラウンド放射の寄与を差し引いた``net flux''を介して行う。
ここで、\(t > \qty{0}{\min}\)を満たす各$i$におけるnet flux \(f_{\mathrm{net},i}\)を以下で与える:
\begin{equation}
  \label{eq:flux_afterxrb}
  f_{\mathrm{net},i} = f_i - f_{\bg} \: (i:t<\qty{0}{\min})
\end{equation}
\eqref{eq:flux_afterxrb}の$f_i$は\(t>\qty{0}{\min}\)のfluxであるから、
\eqref{eq:flux_prexrb}が\textbf{成立しない}ことに注意せよ。

$\fnuneti$の期待値$\mu_{\fnunet,i}$は
\begin{equation}
  E({\fnunet,i}) = E(\fnui + f_{\bg}) = E(\fnui) + \fbghat 
\end{equation}

$f_{\nu,i}$と$f_{\mathrm{bg}}$の間の共分散が十分小さいと見なせるのであれば、
\begin{equation}
  \variance(f_{\nu,\mathrm{net},i}) = \variance(f_{\nu,i}) + \variance(f_{\mathrm{bg}})
\end{equation}
が成り立つ。
\(t>\qty{0}{\min}\)では$f_{\nu,i}$と$f_{\mathrm{bg}}$は異なる時刻での値なので、共分散は小さいと思ってよいだろう。
