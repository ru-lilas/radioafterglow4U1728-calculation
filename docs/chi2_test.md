# Chi-square testによるモデル適合度評価
モデルから計算される光度曲線が観測データを説明できるか
どうかを評価するため、chi-square testを行った。

観測データを $d=(y_i^{\mathrm{obs}},\sigma_i)_{i=1}^{N}$、
モデルから得られる値を $y_i^{\mathrm{model}}(\theta)$とする。
$\theta$は自由パラメータであり、今回は$\theta = (A_{\mathrm{w}},\beta_{\mathrm{sh}})$である。

$\chi^2(\theta)$を以下で定義する：
$$
    \chi^2(\theta) \coloneqq 
    \sum_{i=1}^{N}
    \left(
        \frac{y_i^{\mathrm{obs}}-y_i^{\mathrm{model}}(\theta)}{\sigma_i}
    \right)^2
$$

## "best-fit" パラメータ
本研究では、$\theta$をある範囲で動かしたときの$\chi^2(\theta)$を計算し、その最小値を
"best fit"と定義する。すなわち
$$
    \chi^2_{\mathrm{min}} \coloneqq \min_{\theta} \chi^2(\theta) \\
    \hat{\theta} \coloneqq
    \arg \chi^2_{\mathrm{min}}
$$
である。

ここで得られた$\hat{\theta}$はあくまでも$\chi^2$を最小とする
パラメータとして定義されたものであり、観測データと統計的に整合するかどうかについては
保証していない。

「モデル$\hat{\theta}$が正しいと仮定したとき、
今回得られた$\chi^2_{\min}$は統計的に妥当であるかどうか」
を検証するために、chi-square testを行う。

## Chi-square test
> 帰無仮説$H_0$：モデル$\hat{\theta}$は、観測データ$d$を観測誤差$(\sigma_i)_{i=1}^{N}$の範囲で説明できる。

> 対立仮説$H_1$：モデル$\hat{\theta}$は、観測データ$d$を観測誤差$(\sigma_i)_{i=1}^{N}$の範囲では説明できない。

$H_0$が正しいもとでは、$\chi^2_{\min}$は自由度$\nu = N - n$
の$\chi^2$分布に従う。
ここで$n$は自由パラメータの数で、今回は$n=2$である。

ある$\chi^2_0$の値よりも大きな$\chi^2$が得られる確率
$$
    p = P(\chi^2 \geq \chi^2_0)
$$
を考える。もし$H_0$が正しいとすると、
観測データが$\sigma$の範囲で揺れたとき(何度も観測を行ったとき)
モデル$\hat{\theta}$の生成した$\chi^2_{\min}$またはそれより大きな値が
「それなりの確率」よりも高い確率で出現するはずである。
「それなりの確率」は有意水準$\alpha$とよばれており、検定前に事前に定める。
本研究では$\alpha=0.05$とした。
つまり、$H_0$が正しいのであれば、上で定義した$p$値は$\alpha$よりも
大きくなるはずである。もし$p < \alpha$となるのであれば、
仮説$H_0$がそもそも誤りであったと考えるのが妥当である。
この場合、仮説$H_0$は棄却され、$H_1$を採用する。

## パラメータ
$\varepsilon_{\mathrm{th}} = 1.00,0.80,0.60,0.40$,
$\varepsilon_{\mathrm{B}} = 1.0e-01,1.0e-02,1.0e-03$のそれぞれで$\chi^2_{\min}$を算出し、
$p$値を出した。なおすべての計算について$\mu = 1.00, \mu_{\mathrm{e}} = 0.50$とした。

## 結果
$\varepsilon_{\mathrm{th}} = 1.00,0.80$の場合をそれぞれ示す。

$\varepsilon_{\mathrm{th}}$を1.00より小さくすると全体的に$p$値が減少する
傾向がみられた。

「$\varepsilon_{\mathrm{th}} = 1.00$、かつ観測点の幅を13 minより大きくとった場合」
を除いて、$H_0$を棄却する結果が得られた。

## 結論
「$\varepsilon_{\mathrm{th}} = 1.00$、かつ観測点の幅を13 minより大きくとった場合」
という極端に限定された状況を除いて、$H_0$は棄却される。
このことから、この$\chi^2$フィッティングに基づくモデルでは、
**観測データを再現することは難しい**と結論づけた。

## 今後の課題
今回のフィッティングでは、flux方向の不確かさのみを考慮して得られたものであり、
時間方向の不確かさについては一切考慮していない。

時間方向の不確かさも考慮したフィッティングでモデルが観測データを
再現できるかどうかを調べることで、モデルの妥当性をより詳しく検証することができる。
