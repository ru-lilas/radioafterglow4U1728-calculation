# 2026/07/24
## フィッティングの改良
光度曲線を計算して1 minのbinに切る。1 minで時間平均した光度曲線でフィッティングする。
### 光度曲線の計算
インプット
- 時間配列
- 周波数
- パラメータ(phi_theta,l_theta,tau_theta)

アウトプット
- モデル光度曲線

### 観測データのreduction
インプット
- 観測データ
- 周波数
- 時間窓

アウトプット
- 時間窓領域だけの観測データ

### フィッティング
インプット
- モデル光度曲線
- モデルパラメータの数
- 時間窓領域だけの観測データ

### まとめ
親インプット
- モデルパラメータ表
- 観測データ
- フィッティングの設定
    - モデル光度曲線の時間配列
    - フィッティングしたい周波数
    - フィッティングしたいモデルパラメータの数
    - 観測時間窓
